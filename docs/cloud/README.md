# 云端部署（原生版）

原生 Node 服务仍使用两个回环端口。请由外部反代提供 TLS，管理路径额外保护；模型 Key 只用于模型 API。

- `DW_PUBLIC_ORIGIN`：公开 HTTPS Origin，可含端口，不含路径。
- `DW_PROXY_TOKEN_FILE`：私有文件路径；内容为 48–128 位随机 URL 安全字符。反代覆盖同名请求头，不接受外部传入值。
- `DW_STATE_DIR`：私有持久化状态目录。备份密钥和密文，两者必须一起保留。
- `DW_PANEL_PORT` / `DW_UPSTREAM_PORT`：分别默认 43862 / 43861。不要把这两个监听器直接暴露到公网。

Caddy 路由原则：`/v1/*` 转至回环模型端口，其他路径转至回环面板端口；保留公开 Host；面板的所有路径（包括静态资源）使用管理员认证。两个上游都覆盖写入 `X-Doubao-Proxy-Token`。模型路由保留客户端 Bearer，流式不积压。

服务器无需图形浏览器。在本机项目完成登录后，可导出账号 JSON，登录云端面板导入并核验；或者配置本机助手的私有 `.cloud-target.json`（含 HTTPS `origin`、管理员 `user` 与 `password`），通过 `npm run secure-cloud` 收紧文件权限后，从本机面板明确发起同步。确认目标是自己的服务器；同步会传输所选账号的登录资料。

迁移现有部署前，保留原服务及原始状态目录备份；用空状态启动并检查面板认证、模型 Key、未登录场景和停止流程。正式切换与真实账号的云端模型复测应分别验证。
