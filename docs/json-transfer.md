# 两类 JSON，分别使用

| 文件 | 入口 | 内容 |
| --- | --- | --- |
| 账号备份 `doubao-work-accounts/v1`，version 3 | 工作台 | 登录资料、账号名、备注、转发和签到开关；普通 JSON，敏感 |
| 旧版账号备份，version 2 | 工作台 | 仅迁入豆包工作网页登录快照；不使用旧代理或第三方账号 |
| 接口节点 `doubao-work-nodes/v1`，version 1 | 接口节点 | Base URL、模型 ID、可选 API Key；默认不导出 Key |

账号备份导出时需确认敏感文件。导入最多 20 个账号、512 KB，先预览后确认。重复默认跳过；选择更新也只影响未核验的重复条目。新导入的账号显示「需检查登录」，可点击「核验备份」确认官方身份，也可重新浏览器登录。

接口节点每次最多 50 个、512 KB。远端地址只接受 HTTPS，本机可用 HTTP；不接受 URL 内置凭据。重复节点可更新；未提交 Key 字段时保留旧 Key。节点配置供客户端使用，不会修改网关实际转发目标。

需要迁移只剩数据库的旧账号时，先备份私有状态目录并停止旧服务，再运行 `node launcher.mjs migrate-legacy`（可附加原状态目录参数）。首次迁移保留原签到计划和同日签到状态；新库另存，旧库不改。迁入后仍需身份核验。
